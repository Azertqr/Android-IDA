## Android IDA v1.0

ARM disassembler & decompiler for Android.

### Download
**`Android-IDA-v1.0.apk`** below → install on an ARM phone running Android 7.0 or newer.

### Highlights
- arm64‑v8a and armeabi‑v7a (ARM + Thumb‑2) libraries
- IDA View, Hex View, Strings, Names, Relocations, ELF Info
- Pseudocode decompiler with types, floating point and switch statements (VIP)
- Modify instruction and ARM Converter
- Saved projects (`.aida`)

See the [README](https://github.com/aadilmodsofficial/Android-IDA#readme) for all features.
